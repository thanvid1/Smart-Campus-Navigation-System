# 📍 Smart Campus Navigation System

A **Smart Campus Navigation System** that provides seamless indoor and outdoor navigation using **Augmented Reality (AR), GIS, and intelligent pathfinding algorithms**.

---

## 🚀 Overview

Navigating large campuses can be confusing, especially for new students, visitors, and differently-abled users. This project solves that by providing:

- 📍 Real-time navigation from campus gate to specific rooms  
- 🧭 Indoor + Outdoor navigation integration  
- 🧑‍🦽 Accessibility-aware path suggestions  
- 📱 AR-based directional guidance using smartphone camera  

---

## ❗ Problem Statement

Traditional navigation systems fail because:

- GPS does not work effectively indoors  
- Static maps are outdated and confusing  
- No support for accessibility (ramps, lifts, etc.)  
- Lack of real-time and interactive guidance  

---

## 🎯 Objectives

- Develop a hybrid navigation system (Indoor + Outdoor)  
- Use Augmented Reality (AR) for real-time directions  
- Implement shortest path algorithms like:  
  - A* Algorithm  
- Enable multi-floor navigation using floor plans  
- Provide contextual information (rooms, staff, office hours)  

---

## 🧠 Features

- 📌 AR-based navigation (3D arrows & markers)  
- 📊 Graph-based shortest path calculation  
- 🏢 Multi-floor building navigation  
- ♿ Accessibility-aware routing  
- 📷 QR code-based indoor positioning  
- 🌐 Integration with maps for outdoor navigation  
- 📍 Semantic data (faculty, rooms, services)

## ⚙️ Methodology

The system follows the **Multimedia Development Life Cycle (MDLC):**

- Concept – Problem identification & research  
- Design – UI/UX and system architecture  
- Assembly – Development & integration  
- Testing – Performance & usability testing  

### 🔄 Workflow

- Data collection (maps, floor plans)  
- Convert campus into graph (nodes & edges)  
- User scans QR → sets initial position  
- Algorithm calculates shortest path  
- AR displays navigation in real-time
